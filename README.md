# Завдання РМ-310

Статична сторінка зі статусами всіх завдань і тестів з KNEU Moodle. Без збірки: у Vercel вибрати Framework Preset = Other, корінь = /.

Кольори: зелений — здано/пройдено, жовтий — здано після терміну, червоний — не здано і вже не можна, синій — можна здати зараз, сірий — ще не відкрито, світло-сірий — здавати не треба.
